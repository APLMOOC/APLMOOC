    Function index

    System variables and constants

    Name Meaning
    ⎕A The upper-case English alphabet, 'ABCDEFGHIJKLMNOPQRSTUVWXYZ'

    ⎕PP Print precision, the number of digits displayed
    ⎕IO Index origin, either 1 (the default) or 0
